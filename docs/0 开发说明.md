# Docker 代理配置
Docker提供了一个虚拟环境（创建出数据库和node环境），用于完成单元测试。
在本地电脑不方便配置数据库的时候，用docker非常方便。
Docker拉取镜像，在国内需要用代理。代理配置如下：
Settings > Resources > Proxies
虽然Docker同时支持http和socks代理，但是socks代理是在收费版里面才支持的。
所以要使用http代理，需要在本地先使用ssh创建出socks代理，然后用gost在本地生成http代理。


# .github/workflows 目录
这个目录内含有两个工作流配置文件，可以自动对代码进行测试和发布
release.yml: 自动化部署到npmjs的配置文件
test.yml: 代码提交到github之后，就会自动触发的测试。


# 提交代码到github需要的密码，获取路径（备忘）
github登录的token一段时间后会失效，如果 Cursor 中提示要 GitHub Token，请按以下步骤获取：
生成 Token：登录 GitHub，进入 Settings > Developer settings > Personal access tokens > Tokens (classic)。
设置权限：点击 "Generate new token"，勾选 repo、workflow 和 write:packages 权限。
复制 Token：生成后立即复制（只显示一次）。
Cursor 配置：在 Cursor 终端输入命令或在推送代码弹出登录框时，将 Token 粘贴至密码栏即可。
