# 发布到 npmjs 的流程说明

## 发布流程

`pnpm release` 命令的工作流程如下：

1. **本地执行 `pnpm release`**
   - 执行命令：`bumpp package.json --commit --push --tag`
   - `bumpp` 工具会执行以下操作：
     - 更新 `package.json` 中的版本号
     - `--commit`：自动提交版本更新到 git
     - `--tag`：创建 git tag（格式为 `v*`，如 `v0.1.3`）
     - `--push`：推送代码和 tag 到 GitHub

2. **推送到 GitHub**
   - 代码提交和 tag 会被推送到远程仓库

3. **GitHub Actions 自动触发**
   - 根据 `.github/workflows/release.yml` 配置，当检测到 `v*` 标签被推送时：
     - 自动运行测试（调用 `test.yml`）
     - 测试通过后，自动执行 `pnpm publish --no-git-checks` 发布到 npmjs

## 注意事项

- 发布过程在 GitHub Actions 中完成，而非本地机器
- 需要确保 GitHub Secrets 中已配置 `NPM_TOKEN`
- 发布前建议先运行 `pnpm test` 确保代码通过测试
